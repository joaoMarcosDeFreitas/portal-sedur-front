# Melhorias

- Página do sistema antigo dentro de uma janela. Esta tela é uma página do sistema antigo (api.sedur.salvador.ba.gov.br/k8s/prd/servicosonline/Web/AtividadesPermitidasEmEscritorioVirtual.php) aberta dentro de uma janela de altura fixa (500 px) do portal. O visual, os botões e as fontes são de outro sistema, e o título da aba (“:: SEDUR - Secretaria Municipal de Desenvolvimento Urbano ::”) não é o do portal. Trocar por uma tela do próprio portal.
- Dupla barra de rolagem. A lista tem mais de 300 linhas dentro da janela de 500 px, então a pessoa rola a janela dentro da página.
- Sem explicação. A tela abre direto com “LISTA DE ATIVIDADES PARA ESCRITÓRIOS VIRTUAIS” e uma coluna “CNAE”, sem dizer o que é escritório virtual nem quando a atividade é permitida.
- Sem ajuste para celular. A página do sistema antigo não traz a configuração de tela pequena nem o idioma, o que costuma deixar o texto minúsculo no celular. [a confirmar em um celular]
