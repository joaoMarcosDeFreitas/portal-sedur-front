# Melhorias

- Página do sistema antigo dentro de uma janela. Esta tela é uma página do sistema antigo (api.sedur.salvador.ba.gov.br/k8s/prd/servicosonline/Web/emissaoAlvaraPublicidade.php) aberta dentro de uma janela de altura fixa (500 px) do portal. O visual, os botões e as fontes são de outro sistema, e o título da aba (“:: SEDUR - Secretaria Municipal de Desenvolvimento Urbano ::”) não é o do portal. Trocar por uma tela do próprio portal.
- Sigla sem explicação. A tela tem um único campo, “CGA”, e não diz o que é nem onde a pessoa acha esse número.
- Nome que confunde. “Alvará de Publicidade” parece um pedido de alvará, mas a tela é uma consulta com o botão “Consultar”.
- Sem ajuste para celular. A página do sistema antigo não traz a configuração de tela pequena, o que costuma deixar o texto minúsculo no celular. [a confirmar em um celular]
