# Melhorias

- Página do sistema antigo dentro de uma janela. Esta tela é uma página do sistema antigo (api.sedur.salvador.ba.gov.br/k8s/prd/servicosonline/Web/consulta-AOP.php) aberta dentro de uma janela de altura fixa (500 px) do portal. O visual, os botões e as fontes são de outro sistema, e o título da aba (“:: SEDUR - Secretaria Municipal de Desenvolvimento Urbano ::”) não é o do portal. Trocar por uma tela do próprio portal.
- Nome com concordância estranha e sigla. “Análise de Orientação Prévia (AOP) Emitidas”: fica confuso (“Análise… Emitidas”). Sugestão: “Análises de Orientação Prévia (AOP) emitidas”.
- Filtros por CEP, logradouro, bairro e data de entrada, sem mostrar nada ao abrir.
- Sem ajuste para celular. A página do sistema antigo não traz a configuração de tela pequena nem o idioma, o que costuma deixar o texto minúsculo no celular. [a confirmar em um celular]
